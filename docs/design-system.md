# 设计系统

## 原则

用 MyGo 的原生控件和主题默认值，跟随系统的浅色、深色和强调色。含义用文字表达，不只靠颜色。没有自定义动画，状态变化立即生效。

每个界面先在 `design/` 画板和本文件里写清规格，再写代码；本仓库只认 `design/` 和本文件。

## 颜色

只用 MyGo 主题色，例如次要文字用 `TextMuted`。画板里的颜色是近似值，以真机效果为准。

## 字体

系统字体。目前用到的字号：标题 24 粗体，大数字 48 粗体，提示 12。控件用 MyGo 默认字号。

## 布局和间距

默认窗口 480×320，最小 360×280。外边距 24，纵向间距 16，按钮间距 8，符号按钮宽 44。

## 组件

| 组件 | 用法 |
|---|---|
| `ui.Button` | 次要操作。只有符号的按钮必须用 `.Label()` 给出可读名称。 |
| `ui.PrimaryButton` | 一组按钮里的主操作，最多一个。 |
| `ui.Text` | 文字。次要说明用 `TextMuted`。 |

## 无障碍

按钮有名字，焦点顺序用标准行为。对比度、缩放、键盘和读屏在真机上验，无头测试通过不算数。
